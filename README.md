# Lava-TestLab

Lava TestLab is an interactive web playground for exploring and practicing UI automation testing scenarios. It includes hands-on examples for form inputs, validation, selections, sliders, buttons, overlays, tables, charts, loading states, and broken links and images. A separate Lava E-commerce demo showcases a realistic shopping journey from sign-in through checkout.

Built with React, TypeScript, and Vite. The project is for learning and demonstration; storefront accounts, payments, and orders are simulated.
